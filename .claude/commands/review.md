1. Run `git diff HEAD~1` or `git diff --staged`
2. Check the following aspects:
   - Security vulnerabilities
   - Performance issues
   - Code style violations
   - Potential bugs
3. Report only **actual issues**, do not comment on trivial matters
4. Output concisely, do not write lengthy discourses
